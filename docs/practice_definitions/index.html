Hierarchy. Land-use domain › TNC pathway › practice › variant. Settings on a domain or pathway apply to every practice under it and are shown as "Pathway context" on each practice sheet.

Footprint. Each practice's area is built by applying masks in order: (1) base land cover, (2) farming or production system, (3) commodities, (4) a condition gate such as irrigation control or responsive soils, (5) exclusions and thresholds. TNC's mitigation-eligible area is the shared spatial anchor.

Status. Agreed both sides agreed, or the practice is agreed with one element still open. Priority agreed priority; data or mapping not settled. Proposed one side's proposal. Out dropped or not taken forward.
